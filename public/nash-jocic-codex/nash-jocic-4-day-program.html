Four-day split for most lifters

A detailed week built from Nash's recent split recommendations and body-part workout transcripts. Each muscle is trained once per week with enough focused volume, short rests, strict execution, and full recovery.

2 on / 1 off / 2 on / 2 off Default structure Nash recommends for the majority of natural lifters.

Program Rules

Working sets are the hard sets after warm-ups. Warm-up sets are not counted in the listed volume.

Frequency

Once per week

Train each muscle unit once weekly so muscles, connective tissue, joints, and CNS all recover.

Effort

Stop shy

Most sets should finish 1-2 reps before failure. Failure is occasional, not the default.

Rest

Keep density

Use 30-60 seconds for upper body, 60-90 seconds for hard rows, and 90-120 seconds for legs.

Form

No junk reps

No bouncing, no shortened range to chase load, no long phone breaks, and no ego jumps.

Volume ramp: if you are not adapted to high volume, start with the lower end of the set ranges for 4-6 weeks. Add one set per exercise only when recovery, joints, and performance are stable.

The Week

Example layout: Monday, Tuesday, Thursday, Friday. Move the days if needed, but keep the recovery rhythm.

Days 6-7

Rest

Two days off before restarting chest and biceps.

Recover
Do not fill the weekend with hard HIIT or extra pump workouts. The point of the split is to come back fresh, motivated, and joint-safe for the next chest session.

Progression

Nash repeatedly argues that progression is measured tension, not random weight chasing.

Straight sets

Use one working weight

After warm-ups, keep the same weight across working sets. Reps should drop naturally as fatigue accumulates.

Earn load

Add only after the top range

If the first set exceeds the top target with strict form, add about 5% next time and rebuild from the lower end.

Tempo

Control every rep

Use roughly 1-2 seconds up and at least 2 seconds down. Most sets should last around 30-70 seconds.
